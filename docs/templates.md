# 自定义 Bot 提示与文件名

在 WebUI「设置 → 提示与命名」修改模板，即可查看使用演示数据的示例。点击「保存设置」后生效，保存无需连接 Telegram。「恢复默认提示」「恢复默认文件名」只修改当前表单，仍需保存。

模板用于新生成的 Bot 确认卡。已有卡片、已确认任务和重试继续使用原计划，不会因修改模板而重命名。确认、取消按钮始终由系统提供。

新任务标题优先使用媒体消息附带文字的简短摘要，不再追加编号，与任务列表、详情和 Bot 的入队及结果提示保持一致。媒体组按消息顺序选首条非空文字；无文字时回退到原文件名或媒体类型。文字会合并换行、清理控制字符，最长 80 字。标题不控制单个文件名，文件名仍由下方独立模板配置。列表在标题下显示完整编号；Bot 确认、入队、结果和 `/status` 在独立一行显示 `任务编号：完整ID`，包括自定义确认模板。该系统行无需在模板中添加，模板正文先限长再附加编号。历史冻结标题和已发消息保持原样。

新单文件保存到 `YYYY-MM-DD/`，媒体组保存到 `YYYY-MM-DD/<文字摘要或回退名>/`，不默认附加任务编号。组目录会清理非法字符，完整名称限制为 180 UTF-8 字节；同一天、同一下载根目录中名称冲突时使用 `名称 (2)`、`名称 (3)` 递增，不覆盖已有目录或文件，也不复用其他任务已预留的名称。已有目录和文件不会自动搬迁，已冻结的任务及重试继续使用原路径。该调整不改变单个文件的命名模板。

## Bot 确认提示

支持直接换行，长度为 1–2000 个字符，不能全为空白。默认：

```text
确认下载：{title}
保存到：{destination}
确认有效期：{expires_in_minutes} 分钟
{files}
```

| 变量 | 内容 |
| --- | --- |
| `{title}` | 任务标题：消息文字摘要（无文字时为原文件名或媒体类型）；不追加编号，与 WebUI 一致 |
| `{file_count}` | 文件数量 |
| `{total_size}` | 总大小，使用 KB、MB、GB 等单位；大小不全时显示未知 |
| `{files}` | 计划保存的文件名与大小清单 |
| `{destination}` | 保存目录 |
| `{expires_in_minutes}` | 确认有效期，单位为分钟；非整分钟最多显示两位小数 |

例如：

```text
准备下载 {file_count} 个文件，共 {total_size}
{files}
保存目录：{destination}
请在 {expires_in_minutes} 分钟内确认。
```

确认有效期在「设置 → 下载与保存」以分钟配置，默认 30 分钟，可设 0.5–1440 分钟。提示模板使用 `{expires_in_minutes}` 并标注“分钟”。修改设置只影响后续确认卡，已发卡片的到期时间保持不变。

## 保存文件名

只控制文件名，不改变单文件或同组多文件的归档目录。长度为 1–160 个字符，不能全为空白；不要填写路径或扩展名，系统自动保留原扩展名，缺失时根据视频/图片类型补充。默认 `{name}_{id}`。

| 变量 | 内容 |
| --- | --- |
| `{name}` | 原文件名，不含扩展名 |
| `{date}` | 收件日期，格式 YYYYMMDD |
| `{time}` | 收件时间，格式 HHMMSS |
| `{datetime}` | 收件日期时间，格式 YYYYMMDD_HHMMSS |
| `{type}` | `video` 或 `image` |
| `{index}` | 同一请求中的文件顺序，从 1 开始 |
| `{id}` | 文件短 ID |

日期、时间使用请求创建时刻及设置中的归档时区，并非媒体拍摄时间。示例使用一条原名为 `海边日落.mp4` 的演示视频：

| 模板 | 文件名示例 |
| --- | --- |
| `{name}` | `海边日落.mp4` |
| `{date}_{name}` | `20261020_海边日落.mp4` |
| `{date}_{type}_{index}` | `20261020_video_1.mp4` |

文件名会清理不支持的字符，过长时缩短并保留扩展名；同名文件不会覆盖。为便于区分，建议保留 `{id}` 或加入日期、序号。

两类模板均只支持表内变量。需要显示文字花括号时，连续输入两个左花括号和两个右花括号，例如下面的输入显示为 `{name}`：

```text
{{name}}
```

未知变量、错误括号、表达式和文件名中的路径或非法字符会阻止保存，并保留当前输入供修改。
