# 贡献、安全与许可

## 参与贡献

欢迎通过 [Issues](https://github.com/yebook/TGDL/issues) 反馈问题或提交 Pull Request。普通反馈请提供版本、部署方式、复现步骤与脱敏错误码，不要包含密钥、数据库或真实媒体。

开发环境与检查命令见 [开发指南](development.md)，提交前的范围、检查及协作约定以仓库 [贡献指南](https://github.com/yebook/TGDL/blob/main/CONTRIBUTING.md) 为准。已有变化见 [更新日志](changelog.md)。

## 安全报告

安全问题优先使用仓库 Security 的私密报告入口；若未启用，先请求私下沟通渠道，不公开利用细节。不要发送 Bot Token、API Hash、初始化密钥、密码、数据库或真实媒体。

完整处理方式见仓库 [安全报告指引](https://github.com/yebook/TGDL/blob/main/SECURITY.md)。

## 许可

项目代码按 MIT 许可证分发，允许使用、修改、商用和分发，须保留版权与许可声明，软件按现状提供。完整许可条款以仓库 [MIT LICENSE](https://github.com/yebook/TGDL/blob/main/LICENSE) 为准。

## 构建来源与第三方组件

第三方依赖和官方 Bot API 源码适用各自许可证。项目的本地 API 构建包含代理与进度补丁，不能等同于未修改的官方二进制。

固定源码、基础镜像、补丁与第三方许可位置见仓库 [构建来源](https://github.com/yebook/TGDL/blob/main/deploy/sources.md)。重新分发时请保留项目及相应第三方的版权、许可声明。
