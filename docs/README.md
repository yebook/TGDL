# TGDL 使用文档

在线文档：**https://yebook.github.io/TGDL/**。当前版本与变更见根目录 [更新日志](../CHANGELOG.md)。

## 开始使用

1. [安装到 Docker](deployment.md)，准备目录、权限并启动。
2. [第一次下载](quick-start.md)，连接 Bot，确认并保存一个小文件。
3. [日常设置](settings.md)，按需调整网络、保存、提示、备份和日志。
