# 任务、确认与归档

将视频、图片或同组多文件实际发送/转发给专属 Bot。转发频道的媒体消息通常携带媒体；只发送 `t.me` 链接不在支持范围内。受频道保护而无法转发的内容不能靠本项目绕过限制。

## 确认与结果

Bot 汇总文件数量、可读大小和目标目录，提供「确认下载」「取消」。默认确认有效期 **30 分钟**，可在设置页调整；过期需重新发送媒体。重复点击会按实际状态提示，不会重复创建下载。

确认后进入队列，全局默认同时下载 3 个文件；一组任务逐文件记录结果。Bot 和 WebUI 使用相同标题，完整任务编号单独显示，排障或区分同名任务时使用编号。通知失败与文件保存失败分别记录。

## 目录与命名

```text
downloads/
└── 2026-10-21/
    ├── 单个视频_文件标识.mp4
    ├── 单张图片_文件标识.jpg
    └── 旅行片段_任务短标识/
        ├── 视频_文件标识.mp4
        └── 图片_文件标识.jpg
```

日期使用请求创建时间与设置时区，不是拍摄时间。任务名、组目录优先截取消息文字摘要，无文字时用原文件名或媒体描述；单个文件名由 [文件名模板](templates.md) 控制。没有额外的 `videos/`、`groups/` 分类层。修改模板不搬迁已有文件，也不改变已冻结任务或重试路径。

## 管理任务

任务页可按名称或完整编号搜索、按状态筛选并查看逐文件结果。页面自动更新进度，保留当前滚动与选择。失败项可按状态重试，成功文件不重复保存；取消获取阶段可能需要等待底层服务结束，见 [恢复说明](operations.md#获取阶段取消和重启恢复)。

已结束任务可单条删除或选择当前页多个任务批量删除。删除仅移除记录展示，**不删除媒体文件**，保留必要去重与恢复历史。活动任务先取消并等待结束；若批量中有不允许删除项，整批不执行。

## 设置保存

保存与在线校验分开：Bot Token、白名单可以先离线保存，后续手动校验。保存成功不等于 Bot 已连接；本地 API 的进程状态、切换步骤与 Bot 连接在设置和系统页显示。不要让同一 Bot 同时被多个程序消费。
